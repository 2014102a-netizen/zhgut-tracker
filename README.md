# Трекер комплекта на сертификацию «ЖГУТ 575G»

Статическая страница (GitHub Pages) поверх Google Таблицы. Таблица — источник данных:
статус, исполнителя и примечание можно менять и на странице, и прямо в таблице.

- `index.html`, `app.js` — страница
- `config.js` — адрес веб-приложения Apps Script
- `apps-script/Code.gs` — скрипт для таблицы (чтение и запись)
- `data/seed.json` — снимок на 22.10.2026, показывается, пока таблица не подключена

## Подключение таблицы (один раз, ~5 минут)

1. Открыть таблицу «ЖГУТ 575G — трекер комплекта на сертификацию» на Google Диске.
2. Расширения → Apps Script. Удалить содержимое `Code.gs`, вставить `apps-script/Code.gs`.
3. В строке `const WRITE_KEY = '…'` заменить ключ на свой. Сохранить.
4. Развернуть → Новое развёртывание → тип «Веб-приложение»:
   - Запуск от имени: **Я**
   - У кого есть доступ: **Все**
   Разрешить доступ к таблице, когда Google попросит.
5. Скопировать URL веб-приложения (оканчивается на `/exec`) и вписать в `config.js`:
   `window.TRACKER_API = 'https://script.google.com/macros/s/…/exec';`
6. На странице нажать «Войти» и ввести ключ. Ключ хранится только в этом браузере.

После правки `Code.gs` нужно сделать «Развернуть → Управление развёртываниями → Изменить → Новая версия»,
иначе работает старая версия скрипта.

## Публикация на GitHub Pages

Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → Save.
Через минуту страница будет на `https://2014102a-netizen.github.io/zhgut-tracker/`.

## Безопасность

Страница на Pages публичная: читать её может любой, у кого есть ссылка (поисковикам индексировать запрещено).
Записывать может только тот, кто знает ключ. Не храните в трекере персональные данные и цены.
